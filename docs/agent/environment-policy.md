# 环境与敏感信息策略 · M590Bridge

## 本机环境

写入（可按需创建）：

```text
.agent/local-environment.md
```

可记录：OS 版本、Rust toolchain、测试机主机名别名、局域网测试方式、防火墙备注、Wayland/X11 会话类型等。

**必须 gitignore**（见仓库根 `.gitignore`）。不要把该文件内容粘贴进 `docs/` 共享文档。

## 禁止写入共享文档的内容

- 密码、token、pairing secret 明文长期存档
- 私钥、证书私钥文件内容
- 完整私有连接串、生产主机真实地址与账号
- 可直接定位到个人的敏感绝对路径（若必须说明结构，用占位符）

## 允许的描述方式

- `用户主目录下的项目克隆`
- `同一局域网内的 Windows 测试机`
- `端口默认 47820（示例，实现时可改）`
- 配对码：说明「6 位、短时有效」，不要把真实常用码写进 docs

## 网络与安全默认

- 默认绑定局域网；不做公网暴露假设
- 设备需配对后才同步
- 文档中的端口/协议为设计值，以代码与 task 为准

## 检查到 sensitive warning 时

先判断是否为误报（如字段名 `token` 仅协议字段）。不盲删业务代码；若确为密钥泄露，移出共享文件并轮换凭据。
