## 能力与边界（重要）

| 能力 | 状态 | 说明 |
|------|------|------|
| 1 对 1 配对 + 会话 | 有 | 手动 IP + 配对码；端口默认 5901，hub API 5910 |
| 文本剪贴板双向 | 有 | 轮询；content_id 去重 + 回环抑制 |
| 图片剪贴板双向 | 有 | 线载优先 **PNG**；也可 raw RGBA；超限写 `last_error` |
| 文件管理器「复制图片文件」 | 部分 | 走 file_list / 路径 → 解码为图片再同步（不是传原文件） |
| 粘贴到 Word/画图等 | 有 | 目标应用需支持**图片剪贴板** |
| 粘贴到桌面/资源管理器 | **无** | 桌面要的是**文件列表**语义，不是位图 |
| 通用文件/文件夹传输 | **无** | V2 待做 |
| mDNS / 安装包 / 开机自启 | **无** | 更后 |

## 用户怎么用

```bash
# 两端均建议
git pull
cargo build -p m590-ui
cargo run -p m590-ui
```

1. 一侧创建/等待配对，一侧加入（对端 `IP:5901` + 码）  
2. 开「自动同步」  
3. 复制**文本**或**图片**（截图 / 查看器复制图像 / 复制图片文件）  
4. 对端在 Word、画图等中粘贴  

配置：`M590_CONFIG` 可覆盖；默认 Linux `~/.config/m590bridge/config.cfg`，Windows `%APPDATA%\M590Bridge\config.cfg`。
