## 风险

- 图片两端须同版本（encoding 字段）  
- 大文件需分片与背压，避免再踩 TCP 全量塞内存  
- 托盘 / 重连既有风险仍在  

## 用户怎么用（当前已交付）

```bash
git pull
cargo build -p m590-ui
cargo run -p m590-ui
```

配对后复制文本或图片；对端在支持图片剪贴板的应用中粘贴。
